# PyProg2026Lab5

Лабораторная работа 5 (P3123): регрессия цен на недвижимость — Scikit-Learn.

## Файлы

- `s1p1_predict_house_price_tasks.ipynb` — борд с заполненными ячейками и самостоятельным заданием
- `predict_house_price_training_data.xlsx`, `predict_house_price_test_data.xlsx` — данные

## Запуск

```powershell
pip install pandas numpy matplotlib scikit-learn openpyxl jupyter
jupyter notebook s1p1_predict_house_price_tasks.ipynb
```

Открыть ноутбук и выполнить **Run All** (нужны xlsx в этой же папке).
